# Xpay для Android

Приложение-оболочка вокруг твоего Worker с «мостом» к телефону:
звонки, СМС, открытие приложений, будильник, таймер, фонарик, фоновая голосовая активация.

## Как собрать APK (через GitHub)
1. Создай НОВЫЙ репозиторий (не тот, где лежит Worker), например `xpay-android`.
2. Загрузи туда все файлы из этой папки, включая `.github/workflows/build-apk.yml`.
3. Открой вкладку Actions, выбери Build APK и нажми Run workflow (или просто сделай коммит).
4. Когда сборка станет зелёной, открой её и скачай артефакт `xpay-apk`, внутри `app-debug.apk`.
5. Установи APK на телефон (разреши установку из этого источника).

## Первый запуск
1. Введи адрес своего Worker, например `https://xpay.твой-логин.workers.dev`.
2. В меню чата открой «Приложение: разрешения и фон» и выдай разрешения.
3. Включи «Фоновая активация», потом скажи: «Привет, Xpay, включи фонарик».

Для работы из фона выдай «Показ поверх окон» и «Не ограничивать батарею».
