# Xpay Android — сборка APK

Это подготовленный Android-проект Xpay. APK собирается автоматически через GitHub Actions.

## Как получить APK
1. Создай новый репозиторий GitHub (можно приватный).
2. Загрузи **содержимое** этой папки в корень репозитория (не саму папку целиком).
3. Открой вкладку **Actions** и выбери **Build APK**.
4. Нажми **Run workflow** (или дождись завершения сборки после загрузки файлов).
5. Открой успешный запуск и скачай артефакт **xpay-apk**. Также workflow создаёт Release с файлом `xpay.apk`.

Для установки скачай APK на Android и открой его. Android может попросить разрешить установку из этого источника.

## Важно
- Это debug APK, не подписанный для публикации в Google Play.
- Для работы ИИ нужно отдельно развернуть Cloudflare Worker из папки `worker` и настроить адрес Worker в приложении.
- Голосовые и системные функции могут запросить разрешения Android.
